# Myntra Clone

## About

This is a front-end clone of the Myntra website built using HTML and CSS. The project was created for learning and practicing web development concepts such as page layout, styling, responsiveness, and user interface design.

## Technologies Used

* HTML5
* CSS3

## Features

* Myntra-inspired homepage design
* Navigation bar
* Product sections
* Responsive layout
* Modern UI styling

## What I Learned

* Structuring web pages with HTML
* Styling complex layouts using CSS
* Working with Flexbox and positioning
* Creating responsive designs
* Improving front-end development skills

## Purpose

This project was built for educational and practice purposes. The design is inspired by the Myntra website and was recreated to improve HTML and CSS skills.
